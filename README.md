# jsyrovy/tap

Homebrew casks of my apps.

## Buddr

[Buddr](https://github.com/jsyrovy/buddr) is a pixel-art sheep on your desktop that shows the state of AI coding
agents running in herdr.

```bash
brew install --cask jsyrovy/tap/buddr
```

The full name trusts only this cask. To install and upgrade it by its short name (`brew install --cask buddr`), trust
it first with `brew trust --cask jsyrovy/tap/buddr`.

`Casks/buddr.rb` is updated by a workflow of the Buddr repository whenever a release is published there.
